# AI Consulting Studio — сайт

Статический сайт (HTML + CSS + JS) для GitHub Pages. Сборка и сервер не нужны.

Адрес после включения GitHub Pages: https://vaniavvv12333-blip.github.io/sait_konsalting/

## Структура

| Файл | Что это |
|---|---|
| `index.html` | Главная: услуги, шаги, преимущества, заказ, условия, контакты, реквизиты |
| `oferta.html` | Публичная оферта |
| `privacy.html` | Политика обработки персональных данных |
| `soglasie.html` | Согласие на обработку персональных данных |
| `usloviya.html` | Условия оказания услуг и возврата |
| `oplata-uspeh.html` | Страница возврата после оплаты (Success URL для Robokassa) |
| `oplata-oshibka.html` | Страница неуспешной оплаты (Fail URL для Robokassa) |
| `assets/js/config.js` | **Все настройки: цены, услуги, контакты, ФИО, Telegram, оплата** |

## Как редактировать (прямо на github.com)

Откройте `assets/js/config.js` → значок карандаша (Edit) → внесите правки → **Commit changes**.
Через 1–2 минуты изменения появятся на сайте.

- **ФИО исполнителя** — поле `owner.fullName`.
- **Telegram** — поле `contacts.telegram`, например `"https://t.me/username"`. Пока поле пустое, кнопки Telegram скрыты.
- **Цена или описание** — поля `price`, `description` нужной услуги.
- **Новая услуга** — скопируйте блок `{ ... }` в списке `services`, вставьте после последнего (через запятую) и задайте новый `id`.
  Новая услуга автоматически появится в карточках, в форме заказа, в оферте и в условиях.

## Подключение Robokassa

1. Зарегистрируйтесь в Robokassa как самозанятый и подайте магазин на проверку, указав адрес сайта.
   На сайте уже есть всё, что обычно проверяют: описание услуг, цены, оферта, условия возврата, политика ПДн, контакты, ИНН.
2. В настройках магазина укажите:
   - Success URL: `https://vaniavvv12333-blip.github.io/sait_konsalting/oplata-uspeh.html`
   - Fail URL: `https://vaniavvv12333-blip.github.io/sait_konsalting/oplata-oshibka.html`
   - Включите уведомления о платежах на e-mail — так вы будете узнавать о каждой оплате.
3. После одобрения получите в Robokassa ссылку на оплату для каждой услуги (с фиксированной суммой) и вставьте её в поле `paymentUrl` нужной услуги в `config.js`.
4. Поставьте `robokassa.enabled: true`. На сайте появятся кнопки «Оплатить N ₽».

**Никогда не размещайте в файлах сайта пароли магазина Robokassa (Пароль #1, #2).** Репозиторий публичный.

Сайт статический, поэтому сам не принимает уведомления о платежах (Result URL). Подтверждение оплаты и чек покупателю, а также уведомление о платеже продавцу отправляет Robokassa.
Если понадобится автоматическая обработка заказов (Result URL, формирование подписи на сервере), нужен небольшой серверный обработчик. Его можно добавить отдельно.
